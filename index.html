Configuració

Enganxa l'enllaç CSV publicat del teu Google Sheet. La pàgina el consultarà periòdicament. Per a control remot, canvia la cel·la de l'horari al full.

Format del full: A1 = missatge, B1 = text que es mostrarà; A2 = horari, B2 = una de les opcions: 08:00-09:00, 09:00-10:00, 10:00-11:00, 11:30-12:30, 12:30-13:30 o 13:30-14:30. També pots posar auto a B2 perquè detecti l'horari segons l'hora real.

Al full: Fitxer → Comparteix → Publica al web → selecciona el full i format CSV → Publica. Copia l'enllaç publicat aquí. Qualsevol persona amb l'enllaç podrà llegir el text publicat.
